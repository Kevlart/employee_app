# Система управления персоналом (Flask + SQLAlchemy)

Веб-приложение на Flask + SQLAlchemy для управления базой сотрудников и их иерархией в крупной компании.

## Возможности
```text
📄 Список сотрудников с полной информацией (ФИО, должность, дата приема, зарплата, начальник).
🔃 Сортировка по любому полю — достаточно кликнуть по заголовку столбца.
🔍 Поиск и фильтрация: поиск по ФИО (частичное совпадение) и фильтр по должности.
🌳 Дерево иерархии — наглядное отображение структуры «начальник → подчинённые».
✏️ CRUD-операции: добавление, редактирование и удаление сотрудников.
👤 Быстрая смена начальника с защитой от циклических зависимостей.
🌱 Генерация тестовых данных с помощью библиотеки Faker.
⚠️ Обработка ошибок и понятные flash-сообщения для пользователя.
```

## Стек технологий
Backend: Python 3.9+, Flask, SQLAlchemy (ORM), Flask-WTF (формы), Faker (тестовые данные).
Database: SQLite (по умолчанию), поддержка PostgreSQL/MySQL через изменение строки подключения.
Frontend: HTML5, CSS3

## 📂 Структура проекта
```text
employee_app/
├── app.py                  # Точка входа, инициализация приложения и маршруты
├── config.py               # Конфигурация (DEBUG, SECRET_KEY, SQLALCHEMY_DATABASE_URI)
├── models.py               # Модели SQLAlchemy (Employee, связи и валидация)
├── seed.py                 # 🧪 Скрипт генерации тестовых данных (Faker)
├── requirements.txt        # Зависимости

│   ├── base.html           # Базовый шаблон (наследование, layout)
│   ├── index.html          # Главная страница: список сотрудников + поиск/сортировка

```
    

## Установка и запуск
Предварительные требования
Python 3.9 или выше.
Установленный Git.

### Клонирование репозитория
```text
git clone <URL-репозитория>
cd employee_app
```
### Создание виртуального окружения
- Windows
```text
python -m venv venv
venv\Scripts\activate
```

- macOS / Linux
```text
python3 -m venv venv
```
### Активация виртуального окружения:
```text
source venv/bin/activate
```

### Установка зависимостей
```text
pip install -r requirements.txt
```

### Настройка переменных окружения (опционально)
Для повышения безопасности и гибкости можно вынести чувствительные данные в переменные окружения:
```text
export SECRET_KEY="ваш_секретный_ключ"
export DATABASE_URL="sqlite:///employees.db"  или postgresql://user:pass@host/dbname
```

### Инициализация базы данных и генерация тестовых данных
Запустите приложение хотя бы один раз для создания файла БД (если используется SQLite).
Для генерации тестовых данных можно добавить вызов функции generate_fake_data() в app.py (в режиме разработки) или создать отдельный скрипт seed.py.

### 🚀 Пример запуска:
```text
python app.py
```
### Приложение будет доступно по адресу: http://127.0.0.1:5000.
